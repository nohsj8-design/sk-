# 부산 명소 공공데이터 운영

## 키 등록과 갱신

프로젝트 폴더의 터미널에서 다음을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-busan-api.ps1
```

공공데이터포털의 **부산광역시_부산명소정보 서비스** 활용 승인을 받은 인증키를 입력합니다. 입력은 화면에 표시되지 않으며 명령 기록에도 포함되지 않습니다. Encoding/Decoding 키를 모두 처리하지만 URL 자체가 아닌 키 값만 입력해야 합니다.

키는 프로젝트 최상위 `.env`의 `BUSAN_TOURISM_SERVICE_KEY`에만 저장합니다. `.gitignore`는 등록 스크립트가 자동으로 점검합니다. 키를 채팅, HTML, JavaScript, 공개 JSON, GitHub에 넣으면 안 됩니다. `.env.example`은 빈 형식 안내이며 실제 키를 넣으면 안 됩니다.

키가 이미 등록되어 있다면 관광정보만 갱신합니다.

```powershell
node scripts/fetch-busan-tourism.mjs
```

수집은 HTTPS 국문 API를 페이지당 100건씩 호출합니다. 전체 건수·중복·오류를 검사한 뒤에만 `assets/data/busan-attractions.json`을 교체합니다. 실패하면 기존 자료를 보존하며 인증키나 키가 포함된 요청 URL, 원본 오류 응답은 출력하지 않습니다.

## 사이트 연결

GitHub Pages는 서버 환경변수로 키를 숨길 수 없으므로 브라우저에서 인증 API를 호출하지 않습니다. **로컬 인증 수집 → 공개 관광정보만 정리 → 정적 배포** 구조입니다. 방문자가 페이지를 열 때마다 API를 호출하지 않으며 별도의 유료 서버는 없습니다. 자료 수집일을 페이지에 표시하고 실시간 정보로 표현하지 않습니다.

- 기존 선정 관광 자원과 카드뉴스는 유지합니다.
- API 자료는 별도의 ‘부산을 발견하는 장소들’에 표시합니다.
- 지역·주제 필터, 키워드 검색, 페이지 이동, 상세 소개·운영정보·지도·공식 홈페이지를 제공합니다.
- 원문의 첫 문장을 카드 소개로 요약하며 주제는 제목·장소명 키워드를 바탕으로 편집 분류합니다. 요금·운영시간·휴무일이 없으면 임의로 추정하지 않습니다.
- API 문자열은 `textContent`로 표시하며 외부 URL은 http/https, 인증정보·비밀 파라미터 미포함 조건을 검사합니다.
- `.env`와 원본 인증 요청은 배포하지 않습니다. 갱신 후 공개 JSON과 화면 코드만 커밋합니다.

## 안전한 로컬 미리보기

```powershell
node scripts/preview-portfolio.mjs
```

`http://127.0.0.1:4173/report.html`을 엽니다. 이 서버는 허용한 공개 파일만 제공하며 `.env`·`.git`·서버 스크립트를 제공하지 않습니다. 프로젝트 루트에서 제한 없는 정적 서버를 실행하면 로컬 `.env`까지 노출될 수 있으므로 위 서버를 사용합니다.
