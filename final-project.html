THE ART OF BUSAN / FINAL PROJECT / HWAHYEMOK

화혜목

오래된 손끝, 새로운 감각.
부산의 무형유산과 인디 예술을 오늘의 문화 경험으로 연결합니다.

프로토타입 열기 ↗구현 범위 보기 ↓

기능 시연용 프로토타입 · 실제 예약·결제·제휴는 연결되지 않았습니다.

01 / CONCEPT

콘텐츠에서 체험으로.

예술가와 작품을 발견하는 경험이 체험 탐색으로 이어지도록 정보 구조를 설계했습니다. MAIN, 무형유산 예술가, 인디 예술가, 프로그램 참여, 화혜목 이야기의 다섯 메뉴로 구성합니다.

02 / IMPLEMENTATION

구현한 것과 준비 중인 것.

DISCOVERY

탐색과 비교

프로그램 검색·분류·정렬과 최대 3개 비교 기능을 구현했습니다. 프로그램 정보는 기획 예시입니다.

DEMO FLOW

시연 신청

날짜·인원 선택, 총액 계산, 신청 조회·취소를 브라우저 로컬 저장으로 시연합니다.

NAVIGATION

탐색 도우미

등록된 데이터와 한국어 키워드로 메뉴 이동과 조건 검색을 돕습니다. 규칙 기반 안내 기능입니다.

CONTENT STATUS

콘텐츠 준비

영상·예술가 콘텐츠는 현재 공란입니다. AI 가상영상 등 공개할 콘텐츠를 준비하는 단계입니다.

03 / NEXT

다음으로 이어갈 작업.

공개 콘텐츠 제작, 예술가·프로그램 정보 확정, 실제 신청 접수와 운영 체계 연결이 다음 과제입니다. 팀원별 역할과 성과 수치는 확인된 자료를 바탕으로 추가합니다.
